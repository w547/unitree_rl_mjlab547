你搜索一下有没有什么通过修改参数，进而可以通过操作键盘再去控制机器人的办法？

# 回答

## 结论

没有“只改 YAML 就能把键盘当手柄”的现成参数。`simulate/config.yaml` 原来只有 `use_joystick` 和 `joystick_type: xbox|switch`，下面几条路径都不通：

- `use_joystick: 0`：能建立 DDS 连接，但仿真器不会创建手柄对象，也不会发布 `rt/wirelesscontroller`，部署端 FSM 只能停在 Passive。
- 部署工程自带的 `keyboard_velocity_commands` 观测：只替换 `velocity_commands`，不解决 FSM 迁移；还要把 `deploy.yaml` 的观测名改掉，并让 `g1_ctrl` 终端持有键盘焦点，和 MuJoCo 窗口抢输入，不适合做完整闭环。
- 虚拟 uinput 手柄：可以不改工程代码，但本机 `/dev/uinput` 仅 root 可写，且未安装 `evdev`/`uinput`/`antimicrox`，还需要额外常驻一个键盘到虚拟手柄的映射进程，环境依赖更重。

因此采用第三条路：**在 MuJoCo 仿真器里新增一个“键盘手柄”设备**，把键盘事件映射成 `UnitreeJoystick` 的按键和摇杆值，再照常打包进 `rt/lowstate` 的 `wireless_remote` 和 `rt/wirelesscontroller`。部署工程 `g1_ctrl` 一行不改，物理手柄仍然保留，通过 `joystick_type` 切换。

## 输入链路

```text
键盘 (MuJoCo 窗口)
  → GLFW key callback
  → KeyboardJoystick 按键状态
  → UnitreeJoystick.combine()
  → 仿真器发布 rt/lowstate(wireless_remote) / rt/wirelesscontroller
  → g1_ctrl 的 FSM 迁移 + velocity_commands 观测
  → rt/lowcmd
  → MuJoCo 物理闭环
```

## 键位

| 键盘 | 手柄 | 说明 |
|---|---|---|
| `W` / `S` | 左摇杆 上/下 | 前进 / 后退（`ly`） |
| `A` / `D` | 左摇杆 左/右 | 左移 / 右移（`lx`） |
| `Q` / `E` | 右摇杆 左/右 | 左转 / 右转（`rx`） |
| `↑` `↓` `←` `→` | 十字键 | up / down / left / right |
| `J` `K` `U` `I` | A / B / X / Y | 功能键 |
| `F` / `G` | LT / RT（L2 / R2） | 组合键，建议先按住 |
| `R` / `T` | LB / RB（L1 / R1） | 组合键，建议先按住 |
| `Enter` / `M` | Start / Back | 预留 |

G1 当前 FSM 组合：

- Passive → FixStand：`F` + `↑`
- FixStand → Velocity：`G` + `J`
- Velocity / Mimic → Passive：`F` + `K`
- Velocity → Mimic：`T` + `J`
- Mimic → Velocity：`G` + `J`

## 使用

```bash
cd /home/newname/文档/Trae-CN/temp_20261022_01/robot_rl
./scripts/run_all.sh
```

1. 等 MuJoCo 窗口出现后，先用鼠标点击窗口，让键盘焦点在仿真器上。
2. 先按住扳机键/肩键，再按动作键，例如按住 `F` 再按 `↑` 进入 FixStand。
3. Velocity 下用 `W/S/A/D` 平移、`Q/E` 转向。
4. `F + K` 回到 Passive。

物理手柄到手后，把 `simulate/config.yaml` 的 `joystick_type` 改回 `"xbox"` 或 `"switch"` 即可，无需改代码。

## 验证结果

- `./scripts/build_all.sh -j 20` 编译通过，生成 `g1_ctrl`、`unitree_mujoco`、`jstest`。
- 独立单元测试验证了摇杆、方向键、A/B、LB、LT 的映射。
- `./scripts/run_all.sh --no-build` 启动后不再报 `Joystick open failed`，`g1_ctrl` 正常连接并输出 `FSM: Start Passive`。
- 键盘实测 FSM 全链路：Passive → FixStand → Velocity → Mimic_Dance1_subject2 → Velocity → Passive。
- 实测 `rt/lowstate` 的 `wireless_remote` 在 `F + ↑` 时为 `0x1020`（L2 + up）。
- 实测 Velocity 下按住 `W` 机器人位置发生变化，说明速度指令进入策略并驱动仿真。

## 注意

- 键盘事件只在 MuJoCo 窗口聚焦时有效；窗口失焦会清空按键状态，避免卡键。
- 键盘摇杆只有 -1/0/+1 三档，不如物理摇杆细腻。
- 动作键的 `on_pressed` 是单帧触发，建议每次按键保持 0.3–0.5 s 以上。
- `run_all.sh` 启动 `g1_ctrl` 后会占用终端输入做键盘读取，操作时保持 MuJoCo 窗口焦点即可。
